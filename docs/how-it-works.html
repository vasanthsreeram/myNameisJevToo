How it works

Read the answer before the model writes it.

Give a language model a question and named options. Its next-token probabilities already contain a decision.

Predict tokens. Then read their probabilities.

The shared idea is looking up named tokens in model probabilities. Speculative decoding checks draft tokens across successive positions. Here one model scores answer letters at a single final position.

03 / Keep both numbers

A winning share can hide low option coverage.

Option share tells us which valid answer wins. Raw option mass tells us how much probability the model gave to the valid answers at all.

The HTTP confidence field expresses peakedness of the option shares. The library’s Distribution.confidence is the winning share. Both deserve task-specific calibration.
